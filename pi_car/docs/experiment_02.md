# 실제 AprilTag 캡처 실험 02

사용자가 팔로 들고 있던 카메라로 새 RGB-D 1장을 저장한 뒤 즉시 파이프라인을 종료하고,
촬영 완료를 먼저 알렸다. 분석 중에는 카메라를 다시 사용하지 않았다.
새 카메라 위치이므로 실험 01의 좌표계를 재사용하지 않았다.

- 저장 위치: `data/experiment_02/scene.npz`
- 새 바닥 fitting ROI: (250,230)~(420,410)
- 태그: AprilTag 36h11 ID 16, 휴대폰 화면에 표시됨.
- 검출 중심: (347.5,150.0)px, 평균 한 변 약 14.8px.
- 태그 내부 Depth: 유효 168점, 중앙값 약 1.248m (optical Z).
- 새 로컬 바닥 좌표계의 태그 중심: 약 (0.0462,0.5426,0.0168)m.
- 바닥 평행 가정 방향: 약 -149.1° (태그 +X 기준, 차량 전방 아님).
- 사용자는 실제 태그 변 길이를 모른다고 답했다. 크기를 가정한 PnP는 수행하지 않았다.

`tagcheck.png`는 RGB의 검출 위치·태그 확대·지도 좌표를 함께 보여준다.
`tag_report.json`에 원본 수치를 저장했다.
태그가 약 15px로 작고 실제 위치/방향의 독립 실측값이 없어 좌표 오차와 방향 오차는
평가하지 못했다. 단일 프레임이므로 위치 흔들림/갱신 주기/검출률도 평가하지 않았다.
Depth 기반 크기 추정치가 약 4.9cm이지만 이는 실제 크기 측정을 대체하지 않는다.
Depth의 표면 내 IQR 약 3mm는 위치 정확도나 반복 측정 오차가 아니다.

캡처 이후 카메라를 움직여도 이 저장 영상의 분석에는 영향이 없다.
기존 지도 기준으로 실시간 위치를 추적하려면 카메라를 고정하거나,
카메라를 움직인 뒤 기존 지도 좌표가 알려진 기준점을 통해 다시 보정해야 한다.
