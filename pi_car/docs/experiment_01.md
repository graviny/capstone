# D455 실제 캡처 실험 01

사용자가 카메라 위치를 변경한 뒤 새 캡처를 사용했다. 이전 위치의 보정값을 재사용하지 않았다.
원본 및 이미지·JSON 결과는 Git에서 제외되는 `pi_car/data/experiment_01/`에 저장했다.

## 진행 결과

| 단계 | 결과 |
| --- | --- |
| RGB-D 수신 | 640×480, 깊이 유효 비율 81.9% |
| 바닥 선택 | 영상에서 확인한 바닥 ROI (320,180)~(450,400) |
| RANSAC 바닥 추정 | ROI 지지율 99.88%, 평면 맞춤 RMS 약 3.2mm |

| 차체 여유 적용 | 반경+여유 20cm 가정, 추가 격자 양자화 여유 포함, 사용 가능 322셀 |

| AprilTag | 설정된 36h11 ID 0이 검출되지 않음 |

RGB 픽셀 (489,72)는 로컬 XYZ 약 (0.373,0.731,0.007)m,
(315,313)은 (-0.225,-0.074,0.000)m로 변환됐다.
이를 검사 도구에 넣어 시험 출발점 (0.375,0.735)m,
목표점 (-0.225,-0.075)m가 선택되고 경로 파일이 생성되는 것까지 확인했다.
픽셀 선택은 스크립트로 검사 창의 이벤트 처리에 입력했으며 사람의 마우스 조작은 아니다.

## 결과 파일

- `scene.npz`, `rgb_depth.png`: 이번 위치의 실제 영상/깊이.
- `calibration.json`: 이번 캡처의 로컬 평면 좌표계.
- `map/`: 원본 점유 지도.
- `navigation_map/`: 차체 여유 확장 결과. 원본으로 재사용해 이중 팽창하지 않는다.
- `experiment.png`, `report.json`: 평면·지도·시험 경로 결과.
- `goal.json`, `path.json`: 자동 선정 시험 목표와 경로.
- `click_check/inspection.png`, `click_check/report.json`: 실제 픽셀 선택 처리 결과.

## 검증하지 않은 부분

실측 기준점이 없으므로 절대 좌표 정확도는 검증하지 않았다. 3.2mm는 평면 맞춤 잔차다.
Depth와 평면을 이용한 픽셀 역투영 일치도는 독립적인 실측 정확도가 아니다.
좌표는 이번 카메라 배치의 임시 로컬 좌표이며 음수 XY도 정상이다.
20cm 반경은 실제 차량을 측정한 값이 아니다.
단일 캡처이므로 가림·깊이 구멍은 Unknown으로 남는다.
차량/태그의 위치·방향 추정, Pi 통신, 초음파 회피, 실제 차량 주행은 수행하지 않았다.
다음 위치 추정 실험에는 실측 크기를 설정한 AprilTag를 바닥/차량 위에 놓아야 한다.
