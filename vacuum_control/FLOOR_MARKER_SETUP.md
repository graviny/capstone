# D455 인쇄 마커와 자동 보정

가상환경을 설치한 뒤 아래 명령으로 인쇄 파일을 생성합니다.

```powershell
.\.venv-camera\Scripts\python.exe -m pip install reportlab
.\.venv-camera\Scripts\python.exe export_markers.py
```

PDF는 `output/pdf/capstone-aruco-a4.pdf`에 저장됩니다.
`capstone-aruco-a4.pdf`에 A4 일곱 장이 들어 있습니다. 1–3쪽은 로봇 ID 0·1·2,
4–7쪽은 바닥 ID 10·11·12·13입니다. 모두 `DICT_4X4_50`입니다.

1. **A4, 실제 크기(100%)**로 출력하세요. `페이지에 맞춤`은 끄세요.
   페이지 하단의 100mm 선을 자로 확인하세요. 검은 정사각형 한 변은 로봇용
   120mm, 바닥용 160mm입니다. 자를 때는 검은 테두리 주변에 흰 여백을 남기세요.
2. 바닥에 네 마커의 **검은 정사각형 중심**이 하나의 직사각형을 이루도록
   평평하게 고정하세요. 화살표 네 개를 모두 10–11 변 쪽으로 같은 방향에 맞추세요.
   윗변·아랫변 길이가 같고 두 대각선 길이도 같으면 직사각형 배치를 확인할 수 있습니다.

   ```text
       ↑                        ↑
     ID 10 ───── 가로(m) ───── ID 11
       │                        │
     세로(m)                    │
       │                        │
     ID 13 ────────────────── ID 12
       ↑                        ↑
   ```

3. D455 화면에 네 종이의 검은 정사각형과 흰 여백이 모두 들어오게 하세요.
   로봇 마커의 중심은 로봇 중심에 맞추고, 화살표를 로봇 정면으로 향하게 하세요.
   iPad에 띄운 ID 0도 그대로 사용할 수 있습니다.
4. `navigation_app.py` 미리보기에서 가로·세로에 **마커 중심 간 실제 거리(m)**를
   입력하세요. `로봇 마커 높이(m)`는 바닥부터 종이 또는 화면 표면까지의 수직
   높이입니다. 예를 들어 12cm는 `0.12`입니다. `바닥 마커 한 변(mm)`은 흰
   여백을 제외한 검은 정사각형을 재서 입력하세요. 기본값은 `160`입니다.
5. **`바닥 마커 자동 보정`**을 누르면 네 마커의 꼭짓점 16개로 계산합니다.
   영상에 표시된 ID 배치와 추정 D455 높이를 실측값과 비교하고 `보정 저장`을
   누르세요. 직사각형 바깥이 주행 지도에 포함되도록 하려면 마커를 더 넓게 배치해
   다시 보정해야 합니다. 저장 후에는 로봇의 위치·방향을 지도와 비교하세요.

```powershell
.\.venv-camera\Scripts\python.exe navigation_app.py
```

3m 설치에서는 `--resolution 1280x720`을 붙여 영상에서 각 마커가 충분히 큰지
확인하고 새로 보정하세요. 자동 보정은 바닥 마커 하나라도 누락되면 해당 ID를
알려 줍니다. 배치 오차가 크면 ID 위치, 화살표 방향, 중심 간 거리, 검은 변 길이를
확인하세요. 카메라를 고정한 뒤 같은 설치에서는 저장한 보정을 재사용할 수 있습니다.
작은 구역도 보정할 수 있습니다. 주행 경로를 만들려면 바닥 경계와 장애물에서
로봇 반경 및 여유 거리를 뺀 뒤에도 로봇 중심이 이동할 공간이 있어야 합니다.

프로그램은 한 번에 선택한 로봇 한 대를 추적합니다. ID 1이나 2를 사용할 때는
`--marker-id 1` 또는 `--marker-id 2`를 붙이세요. `--drive`에서 선택한 ID의 실물
청소기에 맞는 `--ip`와 토큰을 사용하세요. 로봇 마커 높이가 바뀌면 보정에도
새 높이를 반영하세요.
