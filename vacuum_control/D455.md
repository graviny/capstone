# Windows에서 D455 연결

USB 3 데이터 케이블로 D455를 PC에 직접 연결합니다. 첫 시험은 짧은 케이블로
진행하고, 연결이 안정적인지 확인한 뒤 천장 설치용 배선을 결정하세요.

## 가상환경

[README의 Windows 설치 절차](README.md#windows에서-설치)를 마친 뒤 이 폴더에서 PowerShell을 실행합니다.
이 문서의 명령은 `.venv-camera`의 Python을 바로 호출합니다.

## 1. 장치 인식

```powershell
.\.venv-camera\Scripts\python.exe realsense_camera.py list
```

`Intel RealSense ... D455`와 USB 연결 정보가 나오면 기기를 찾은 것입니다.
USB는 3.x 연결을 사용하세요. 기기가 안 보이면 케이블/포트를 바꾸어 봅니다.

## 2. 컬러/깊이 프레임 수신

Viewer나 다른 카메라 앱이 D455를 사용 중이면 먼저 스트리밍을 끕니다.

```powershell
.\.venv-camera\Scripts\python.exe realsense_camera.py probe
```

30프레임을 읽은 뒤 `PASS`와 컬러/깊이 영상 크기가 나옵니다. 영상은 저장하지
않습니다. `runtime/d455_camera.json`에 기기 정보와 카메라 내부 파라미터만
저장합니다. 이것은 바닥 좌표 보정 결과가 아닙니다.

## 3. 영상과 마커 인식

```powershell
.\.venv-camera\Scripts\python.exe camera_demo.py track --source realsense
```

왼쪽은 컬러 영상 및 마커 인식, 오른쪽은 컬러 영상에 정렬된 깊이 영상입니다.
마커가 없어도 두 영상이 나오면 카메라 연결을 확인할 수 있습니다. ID 0의 인쇄용
마커를 비춰 테두리와 화살표가 나오는지 확인하세요. Q/Esc로 종료합니다.

기본 프로파일은 컬러와 깊이 각각 640x480, 30fps입니다. 먼저 연결을 검증하는
설정이며, 최종 시연 영역에 맞춰 프로파일을 정한 뒤 위치 보정을 해야 합니다.
프로파일을 바꾸면 보정 자료도 해당 프로파일에 맞게 다시 확인해야 합니다.

검출 결과의 `marker_depth_z_m`는 카메라 광축 방향 깊이(Z)입니다. 카메라와의
직선 거리, 로봇의 바닥 높이, 창고 x/y 좌표와는 다릅니다. `depth_valid`가
false이면 깊이 값을 사용할 수 없습니다. 현재 코드는 영상 픽셀 좌표만 출력하며
로봇 이동 명령을 보내지 않습니다.

## RealSense Viewer를 사용하는 방법

제조사 공식 [릴리스 페이지](https://github.com/realsenseai/librealsense/releases/latest)의
Assets에서 Windows용 Viewer 또는 SDK 설치 파일을 받을 수 있습니다. Viewer에서
D455를 선택하고 Stereo Module의 Depth와 RGB Camera의 Color 스트림을 켜면
색상 영상과 깊이 영상을 확인할 수 있습니다. SDK 설치와 Python 패키지 설치는
별개이며, 위 Python 시험에는 `pyrealsense2`가 필요합니다.

연결 확인을 위해 펌웨어를 자동으로 업데이트하지 않습니다. SDK와 펌웨어 호환
오류가 나오면 오류 내용을 확인한 뒤 해당 기기에 맞는 조합을 결정합니다.
